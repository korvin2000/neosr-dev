# T1 (final): loss pipeline and training step

Inputs: the synthesis draft (`design/T1_draft.md`), the Fable adversarial review (GPU and 2-rank DDP probes `design/t1_review_*.py`), and the Codex adversarial review (`design/codex_T1_adversarial.md`). Each critique point was checked against `/home/korvin/apps/neosr-dev` at `55f0cdd`, which was read but not modified. The design is aligned with T2 (`T2_draft.md`: trainer structure, counters, checkpoint), T3 (`T3.md`: config, factory, entry points), T4 (`T4_draft.md`: feature triage, perf) and T5 (`T5_aether_qat.md`).

One new GPU probe was run for this document: `design/t1_final/phase_probe.py` (RTX 4090, torch 2.9.1). It runs the final `Phase` and `Ema` below in fp32, bf16 and fp16, with four inputs each: clean, NaN gradient, inf gradient, and finite gradients whose norm overflows. Results:
- Every bad update was skipped. Live and EMA weights stayed bitwise unchanged and the grads were cleared.
- The fp16 scale halved on an inf/NaN skip. A norm-overflow skip left the scale unchanged.
- The first good update copied the live weights into the EMA.
- Each update costs one host sync. fp16 adds the scaler's own check, which reads an already drained stream.
- 3 consecutive bad updates raised at `max_streak=3`.

## 0. Design in twelve lines

1. A loss is an `nn.Module` with three methods. `forward(*tensors)` is the unweighted numeric kernel. `evaluate(ctx)` chooses inputs and models, and is the only override point. `compute(ctx)` applies the weight once, handles fp32, checks for a scalar and logs.
2. The trainer loop is `sum(t.compute(ctx) for t in phase.terms)`. It has no `if`/`isinstance` chain and no GAN knowledge. The owner's requirement is met.
3. `build_losses` reads every `train.<slot>_opt` table generically. It pops `loss_weight`, maps the legacy globals (`match_lq_colors`, `wavelet_guided`/`wavelet_init`) to per-loss keys, prunes zero-weight G terms, validates dependencies and reserved keys, and freezes all loss modules once.
4. `gan_loss` expands into a G term (D sees `view(sr)`, gradient flows to G only) and a D term (fresh forwards on `view(gt)` and `view(sr.detach())`). `AdvView` is the wavelet view: fp32, differentiable, built once, the same for G and D.
5. The G objective runs D in train mode through a D handle with no DDP reducer, and calls `backward(inputs=G params)`. D never receives G-pass gradients. Nothing is frozen or toggled.
6. Each optimizer has one `Phase`: terms, optimizer, fp16-only `GradScaler(init_scale=2**5)`, clipping, schedulers and skip accounting.
7. Non-finite handling is strict and is the only mode. `ok = isfinite(total_grad_norm)` costs one host sync per update. A bad update is skipped cleanly: weights, EMA and optimizer state are untouched. `max_skip_streak` consecutive skips raise.
8. A non-finite objective, or non-finite weights or buffers, aborts at the next log or `check_finite()`. `check_finite()` runs on every rank before each validation and save, so no checkpoint is ever written from bad state.
9. EMA is a small `Ema` class over the bare eager G. The first successful update copies the weights, as `AveragedModel` did. Later updates `lerp` the parameters and copy the buffers, and only successful updates advance it.
10. Accumulation has one counter, `self.micro`, owned by the model. `boundary` is computed first. DDP `no_sync` encloses G forward + loss + backward. The scale `1/accumulate` is applied once.
11. Logging uses detached device sums with per-key counts. Each `print_freq` costs one stack, one `all_reduce` and one `tolist`. The keys are today's, plus `grad_norm_{g,d}` and `skipped_{g,d}`. `l_d_total` = real + fake.
12. Deleted: SAM, ECO, D-EMA, DataParallel, `sr_ema`, `update_learning_rate`/`warmup_iter`, the GAN weight schedule, `reduce_loss_dict`, `loss_util.py`, and the legacy model files.

- **F #9, C #10: antialias.** See D4.
- **F #10, C #6: QAT and EMA.** See D21. EMA is built after T5's prepare+prime (T2 §3 invariant), and the first-copy `load_state_dict` tolerates resized observers. `_init_ema` is deleted (T4/T5).

- **C #4 "track objective non-finiteness in the step gate":** rank-local objectives would let DDP ranks diverge. The deferred abort cannot corrupt weights (D15).
- **C #13 "recording registry insufficient":** agreed, so A1's dry run builds the real constructors (§6). This item was not rejected; it was absorbed into §6.

- **T4 P1(b) "gate scheduler on finite":** clock = attempted updates (D20).

- **T2 §9 "`it=self.update`":** off by one against today's thresholds (D19).

### 4.1 `neosr/losses/base.py` (new, T1 A1)

```python
"""Loss contract. A loss reads what it needs from Context; trainers only call compute(ctx)."""
from contextlib import nullcontext
from functools import cached_property

import torch
from torch import Tensor, nn
from torch.nn import functional as F


class Context:
    """What one generator forward exposes to the losses. Built by the trainer; losses only read it."""

    def __init__(self, *, sr: Tensor, gt: Tensor, lq: Tensor, it: int,
                 net_d: nn.Module | None = None, net_d_adv: nn.Module | None = None) -> None:
        self.sr, self.gt, self.lq, self.it = sr, gt, lq, it
        self.net_d = net_d            # D execution wrapper (DDP/compile): D's own update
        self.net_d_adv = net_d_adv    # D without a DDP reducer: the generator's adversarial pass
        self.logs: dict[str, Tensor] = {}

    @cached_property
    def lq_up(self) -> Tensor:        # colour reference (was match_lq_colors, image.py:525-534)
        with torch.no_grad(), torch.autocast("cuda", enabled=False):
            up = F.interpolate(self.lq.float(), size=self.sr.shape[-2:], mode="bicubic", antialias=True)
        return up.clamp_(1 / 255, 1)

    def log(self, key: str, value: Tensor) -> None:
        self.logs[key] = value.detach()


class Loss(nn.Module):
    """forward(*tensors) is the unweighted kernel. evaluate(ctx) picks inputs/models. compute(ctx) is final."""
    loss_weight: float = 1.0          # class default; the builder sets the instance value
    target: str = "gt"                # attribute of Context used as the reference: "gt" | "lq_up"
    phase: str = "g"                  # objective this term joins: "g" | "d"
    log_key: str = ""                 # set by the builder; "" = not logged on its own
    fp32: bool = False                # run outside autocast with fp32 inputs (was custom_fwd(cast_inputs=float32))

    def expand(self) -> list["Loss"]:
        return [self]

    def evaluate(self, ctx: Context) -> Tensor:
        sr, ref = ctx.sr, getattr(ctx, self.target)
        return self(sr.float(), ref.float()) if self.fp32 else self(sr, ref)

    def compute(self, ctx: Context) -> Tensor:
        with torch.autocast("cuda", enabled=False) if self.fp32 else nullcontext():
            value = self.evaluate(ctx) * self.loss_weight          # the only place a weight is applied
        if value.ndim:
            raise ValueError(f"{type(self).__name__} returned shape {tuple(value.shape)}, expected a scalar")
        if self.log_key:
            ctx.log(self.log_key, value)
        return value
```

Kernel recipe (B1). Per loss class:
- Base class `nn.Module` → `Loss`.
- Delete the `loss_weight` ctor argument, `self.loss_weight = ...` and the `* self.loss_weight`.
- Replace `@torch.amp.custom_fwd(cast_inputs=torch.float32, device_type="cuda")` on `forward` with the class attribute `fp32 = True`.
- Drop `**kwargs` sinks (T3 L-D).

Nothing else changes. Example `L1Loss`: `class L1Loss(Loss): def forward(self, x, y): return F.l1_loss(x, y, reduction=self.reduction)`.

def build_losses(train: Mapping[str, Any], *, scale: int, device: torch.device,
                 has_d: bool) -> tuple[list[Loss], list[Loss]]:

    for key, cfg in train.items():
        if not key.endswith("_opt") or not cfg:
            continue

        if "loss_weight" in spec and "perceptual_weight" in spec:
            raise ConfigError(f"[{section}] set loss_weight or perceptual_weight, not both")
        weight = spec.pop("loss_weight", spec.pop("perceptual_weight", None))
        target = spec.pop("target", "gt")
        if target not in TARGETS:
            raise ConfigError(f"[{section}] target must be one of {sorted(TARGETS)}")
        loss = build_loss(spec, scale=scale, section=section)                    # T3 factory (type -> class)
        loss.loss_weight = float(type(loss).loss_weight if weight is None else weight)
        if not math.isfinite(loss.loss_weight):
            raise ConfigError(f"[{section}] loss_weight must be finite")
        loss.target, loss.log_key = TARGETS[target], f"l_g_{SLOT_KEY.get(name, name)}"
        terms += [t for t in loss.expand() if t.phase == "d" or t.loss_weight]

    g = [t for t in terms if t.phase == "g"]
    d = [t for t in terms if t.phase == "d"]
    keys = [t.log_key for t in terms if t.log_key]
    if not g:
        raise ConfigError("[train] at least one generator loss with a non-zero weight is required")
    if has_d != bool(d):
        raise ConfigError("[train] network_d requires gan_opt and gan_opt requires network_d")
    if train.get("wavelet_guided") and not d:
        raise ConfigError("[train] wavelet_guided requires gan_opt")
    if len(set(keys)) != len(keys) or any(k in RESERVED or k.startswith(RESERVED_PREFIX) for k in keys):
        raise ConfigError(f"[train] loss log keys must be unique and not reserved: {keys}")
    nn.ModuleList(terms).to(device).requires_grad_(False).eval()                 # after construction (DISTS alpha/beta)

class AdvView(nn.Module):
    """Identity before start_iter, then the 3 scaled SWT high-frequency bands of Y.
    fp32, differentiable, built once; the same op for the G and D terms."""

    def __init__(self, start_iter: int = 0) -> None:
        super().__init__()
        self.start_iter = start_iter
        w = pywt.Wavelet("sym19")                                         # filters exactly as wavelet_guided.py:388-396
        lo = np.divide(w.dec_lo, sum(w.dec_lo)); slo = 2 * np.divide(w.rec_lo, sum(w.rec_lo))
        self.swt = SWTForward(1, pywt.Wavelet("wavelet_normalized", [lo, w.dec_hi, slo, w.rec_hi]), "periodic")
        self.register_buffer("y_w", torch.tensor([65.481, 128.553, 24.966]).view(1, 3, 1, 1), persistent=False)
        self.register_buffer("band_w", torch.tensor([0.035, 0.025, 0.02]).view(1, 3, 1, 1), persistent=False)

    def forward(self, x: Tensor, it: int) -> Tensor:
        if it < self.start_iter:
            return x
        with torch.autocast("cuda", enabled=False):
            y = 16.0 + (x.float() * self.y_w).sum(1, keepdim=True)       # == wavelet_guided.py:403-407
            return self.swt(y)[0][:, 1:4] * self.band_w                   # LH, HL, HH scaled (:410-414)

```python
class gan_loss(Loss):
    """[train.gan_opt]: the generator's adversarial term; expand() adds the discriminator's term."""
    loss_weight = 0.1

    def __init__(self, gan_type: str = "bce", real_label_val: float = 1.0, fake_label_val: float = 0.0,
                 wavelet_init: int | None = None) -> None:
        super().__init__()
        self.crit = {"bce": nn.BCEWithLogitsLoss, "mse": nn.MSELoss, "huber": nn.HuberLoss}[gan_type]()
        self.labels = (fake_label_val, real_label_val)
        self.view = AdvView(wavelet_init) if wavelet_init is not None else None

    def adv(self, x: Tensor, it: int) -> Tensor:
        return x if self.view is None else self.view(x, it)

    def term(self, logits: Tensor, real: bool) -> Tensor:
        return self.crit(logits, torch.full_like(logits, self.labels[real]))

    def evaluate(self, ctx: Context) -> Tensor:               # train-mode D, no reducer; grads reach sr only
        return self.term(ctx.net_d_adv(self.adv(ctx.sr, ctx.it)), True)

    def expand(self) -> list[Loss]:
        return [self, gan_d_loss(self)]


class gan_d_loss(Loss):
    """Discriminator objective, unweighted (gan_loss.py:83-84)."""
    phase = "d"

    def __init__(self, g: gan_loss) -> None:
        super().__init__()
        self.g = g

    def evaluate(self, ctx: Context) -> Tensor:
        real = ctx.net_d(self.g.adv(ctx.gt, ctx.it))
        fake = ctx.net_d(self.g.adv(ctx.sr.detach(), ctx.it))
        l_real, l_fake = self.g.term(real, True), self.g.term(fake, False)
        for k, v in (("l_d_real", l_real), ("l_d_fake", l_fake),
                     ("out_d_real", real.mean()), ("out_d_fake", fake.mean())):
            ctx.log(k, v)
        return l_real + l_fake
```

```python
class Phase:
    """One network's objective: terms, optimizer, fp16 scaler, clipping, schedulers, skip accounting."""

    def __init__(self, name: str, params: list[nn.Parameter], opt: Optimizer,
                 terms: list[Loss], *, amp_dtype: torch.dtype, use_amp: bool, accumulate: int,
                 grad_clip: float, max_skip_streak: int = 10, schedulers=()) -> None:
        self.name, self.params, self.opt, self.terms = name, params, opt, terms
        self.autocast = {"device_type": "cuda", "dtype": amp_dtype, "enabled": use_amp}
        self.scaler = torch.amp.GradScaler("cuda", enabled=use_amp and amp_dtype is torch.float16,
                                           init_scale=2.0**5)
        self.inv_accum, self.grad_clip, self.max_skip_streak = 1.0 / accumulate, grad_clip, max_skip_streak
        self.schedulers = list(schedulers)
        self.skipped = self.streak = 0                 # host ints: skipped in the log window, consecutive skips
        self.grad_norm: Tensor | None = None           # device scalar of the last successful update

    def backward(self, ctx: Context) -> None:
        with torch.autocast(**self.autocast):
            total = sum(t.compute(ctx) for t in self.terms)
        ctx.log(f"l_{self.name}_total", total)          # undivided micro-batch objective
        self.scaler.scale(total * self.inv_accum).backward(inputs=self.params)

    def step(self) -> bool:
        self.scaler.unscale_(self.opt)                                        # no-op unless fp16
        norm = get_total_norm([p.grad for p in self.params if p.grad is not None], foreach=True)
        if self.grad_clip:
            clip_grads_with_norm_(self.params, self.grad_clip, norm, foreach=True)
        ok = bool(norm.isfinite())                     # the one host sync per update; rank-identical under DDP
        if ok:
            self.scaler.step(self.opt)                 # fp16: re-checks found_inf on the drained stream
            self.grad_norm = norm
        self.scaler.update()                           # fp16: halves the scale after an inf/NaN window
        self.opt.zero_grad(set_to_none=True)
        for s in self.schedulers:                      # clock = attempted updates
            s.step()
        self.skipped += not ok
        self.streak = 0 if ok else self.streak + 1
        if self.streak >= self.max_skip_streak:
            raise FloatingPointError(f"net_{self.name}: {self.streak} consecutive non-finite updates; "
                                     "restart from the last checkpoint with a lower learning rate")
        return ok


def no_sync(net: nn.Module, boundary: bool):             # DDP: reduce only on the window's last micro-batch
    return net.no_sync() if not boundary and hasattr(net, "no_sync") else nullcontext()


class Ema:
    """EMA of the bare eager G. First successful update copies (AveragedModel semantics); later ones lerp."""

    def __init__(self, net: nn.Module, decay: float) -> None:
        self.net, self.w, self.lists = net, 1.0 - decay, None
        self.module = copy.deepcopy(net).eval().requires_grad_(False)

    def _bind(self) -> None:
        self.lists = ([*self.module.parameters()], [*self.net.parameters()],
                      [*self.module.buffers()], [*self.net.buffers()])

    @torch.no_grad()
    def update(self) -> None:                          # called only after a successful G update
        if self.lists is None:
            self.module.load_state_dict(self.net.state_dict())   # also resizes per-channel QAT observers
            return self._bind()
        dp, sp, db, sb = self.lists
        torch._foreach_lerp_(dp, sp, self.w)
        if db:
            torch._foreach_copy_(db, sb)

    def state_dict(self) -> dict:
        return self.module.state_dict()

    def load_state_dict(self, sd: dict) -> None:       # resume: the EMA is already initialised
        self.module.load_state_dict(sd)
        self._bind()


class LossMeter:
    """Detached device sums with host counts per key; one stack + all_reduce + tolist per read."""

    def __init__(self) -> None:
        self.sum: dict[str, Tensor] = {}
        self.n: dict[str, int] = {}

    def add(self, logs: Mapping[str, Tensor]) -> None:
        for k, v in logs.items():
            s = self.sum.get(k)
            self.sum[k] = v.float().clone() if s is None else s.add_(v)
            self.n[k] = self.n.get(k, 0) + 1

    def read(self, reset: bool = True) -> dict[str, float]:
        keys = list(self.sum)
        if not keys:
            return {}
        vec = torch.stack([self.sum[k] / self.n[k] for k in keys])
        if dist.is_initialized():
            dist.all_reduce(vec, op=dist.ReduceOp.AVG)                       # collective: call on all ranks
        out = dict(zip(keys, vec.tolist()))
        if reset:
            self.sum.clear(); self.n.clear()
        if bad := [k for k, v in out.items() if not math.isfinite(v)]:
            raise FloatingPointError(f"non-finite training values {bad}; nothing was saved from this window")
        return out
```

```python
def optimize_parameters(self) -> bool:
    """One micro-batch. Returns True when this micro-batch closed an update window."""
    boundary = (self.micro + 1) % self.accumulate == 0
    with no_sync(self.net_g_fwd, boundary):                           # forward + losses + backward (D12)
        with torch.autocast(**self.g.autocast):
            sr = self.net_g_fwd(self.lq)
            if self.clamp:
                sr = sr.clamp(1 / 255, 1)
        ctx = Context(sr=sr, gt=self.gt, lq=self.lq, it=self.update + 1,
                      net_d=self.net_d_fwd, net_d_adv=self.net_d_adv)
        self.g.backward(ctx)
    if self.d is not None:                                            # structural, not per-loss
        with no_sync(self.net_d_fwd, boundary):
            self.d.backward(ctx)
    self.meter.add(ctx.logs)
    self.micro += 1
    if not boundary:
        return False
    if self.g.step() and self.ema is not None:
        self.ema.update()
    if self.d is not None:
        self.d.step()
    self.meter.add({f"grad_norm_{p.name}": p.grad_norm for p in self.phases if p.grad_norm is not None})
    self.update += 1
    return True

def get_current_log(self) -> dict[str, float]:
    out = self.meter.read()                                           # collective; raises on non-finite (D15)
    for p in self.phases:
        out[f"skipped_{p.name}"], p.skipped = p.skipped, 0
    return out

def check_finite(self) -> None:
    """All ranks, before validation and save. Raises before bad state reaches disk or metrics."""
    self.meter.read(reset=False)
    nets = [self.net_g, *([self.ema.module] if self.ema else []), *([self.net_d] if self.net_d else [])]
    ts = [t for n in nets for t in (*n.parameters(), *n.buffers()) if t.is_floating_point()]
    if not bool(torch.stack(torch._foreach_norm(ts)).isfinite().all()):
        raise FloatingPointError("non-finite weights or buffers; the last committed checkpoint stands")
```

`grad_norm_*` is added only for successful updates, so a stale value from an earlier window is possible after a fully skipped window. The `skipped_*` log key shows when that happened. `otf.py` inherits all of this unchanged (it overrides only `feed_data`, T2 §7.5).

## 8. Risks

1. **Intended dynamics change.** G now trains adversarially through a train-mode D, on HF bands from `wavelet_init`. D's own regime also changes: SN power iteration, dropout 0.2 and DropPath 0.02 become active. Expect different curves. A short A/B of `gan_opt.loss_weight` (0.1 vs 0.3) on `train_esrgan2.toml` with `wavelet_init` lowered is the owner's run.
2. **Strict sync per update.** Measured at 0.1–0.3 ms. A launch-bound tiny net (span at batch 16) loses CPU run-ahead once per update. Accepted for "stable". Measure in B2's profiler run.
3. **Forward-mutated buffers.** A skipped update does not roll back BN running stats or QAT observers in G that a NaN forward already touched. `check_finite` catches this before any save. Training can continue with a bad buffer until then (≤ `print_freq` updates, then it aborts at the next check).
4. **DDP.** Verified on gloo with one GPU only. NCCL multi-GPU is unverified (step E). Under DDP, D's BN running stats are rank-local (unused, since D is always in train mode).
5. **Cached parameter lists** (`Phase.params`, `Ema.lists`) assume no structural change after construction. This is T2's §3 invariant.
6. **Accumulation ≠ full batch** for batch-statistic losses and train-mode D buffers. This is unchanged from today.
7. **`get_total_norm`/`clip_grads_with_norm_`** are public since torch 2.6. The repo is pinned at 2.9.1.

## 9. Rejected ideas

- `isinstance`/label dispatch in the loss loop, or `forward(ctx)` kernels: they violate the owner's rule or make kernels untestable.
- `LossResult`/collection objects and a loss dependency graph: the single multi-part loss logs through `ctx.log`.
- A shared mutable `ctx` cache for the adversarial view: it couples G and D ordering, and recompute costs about 0.2 ms.
- Freeze/restore of D's `requires_grad`: DDP-hostile, and `backward(inputs=)` is equivalent (D8).
- Non-strict (deferred-abort) bf16, the private `_amp_foreach_non_finite_check_and_unscale_`, device-weighted EMA, `torch.where`-shielded EMA: strict is simpler, safer, and 0.1–0.3 ms.
- The fused-AdamW `found_inf` adapter: the 6 AdamW configs are unfused fp32, and it depends on private scaler state.
- Success-gated or tensor LR schedules: 0 scheduler users.
- Persisting loss modules in `.state`: it drags in backbones (D30).
- `[[train.losses]]` now (D27).
- Keeping or re-adding SAM, ECO, D-EMA, DataParallel, `sr_ema`, `warmup_iter`, `net_d_iters`, or a GAN weight schedule.
- Concatenating real and fake into one D forward: it changes BN-D statistics. `broadcast_buffers=False` is enough.
- Compiling the trainer step, or a callback framework.
