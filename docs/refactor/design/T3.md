# T3 (final): configuration, construction, imports, RNG, devices, error handling

This version merges the draft (`T3_draft.md`) with the Fable and Codex critiques. Every critique point was checked against `/home/korvin/apps/neosr-dev` (commit `43db06a`), read-only. Line numbers refer to that checkout. The implementation base is the `refactor/stabilize` worktree, which already carries in-flight stabilization edits. Lanes must re-read the current file before editing. Where those edits differ from this design (for example, `data/__init__.py:seed_data_rngs` rebinds three module generators), this design supersedes them.

Cross-topic owners: **T1** owns the loss contract and training step, **T2** owns models, checkpoints and init order, **T4** owns feature deletions and optimizers, and **T5** owns aether and QAT. Where T3 needs a change in a file another topic owns, it hands over a seam checklist (§5, L-D/L-E) instead of claiming the file.

## 0. Summary

1. Code under `neosr/` never reads argv or TOML at import, and never touches CUDA, RNG or the process group. Each entry point's `main(argv)` parses argv once. The following are deleted: `net_opt()`, `utils/rng.rng()`, `utils/options.py` and `utils/registry.py`.
2. Explicit lazy tables `name -> (module, scale_kw)` replace `Registry`, the decorators, folder scanning and the star-imports. A shared `resolve()` sits under thin per-package builders, because the call shapes differ.
3. `build_network(cfg, scale=..., section=...)` injects the run scale using the arch's native kwarg name. An explicit value that contradicts the scale is a `ConfigError`.
4. `load_config()` is pure. It validates the TOML and derives keys, but never inserts defaults for absent optional keys. Unknown keys produce a warning with a did-you-mean suggestion. Wrong types, missing required keys, unknown component types and removed features produce a `ConfigError`.
5. `setup_runtime()` runs once per entry point. It returns a frozen `Runtime(device, rank, world_size, seed, distributed)` with one distributed contract and a local-rank device.
6. RNG uses one process-wide numpy `Generator` that is reseeded in place. Workers are seeded from `get_worker_info().seed`. The sampler is seeded with `seed + epoch` on the CPU. The switch is atomic, with no shim.
7. There is no global default device. Devices and dtypes are chosen separately: accumulators and coordinate grids stay in fp32.
8. Library code raises. Only `main()` exits, with code 0 (also for a graceful stop), 1 (unexpected error, traceback logged once), 2 (`ConfigError`) or 130 (second Ctrl-C).

## 3. Code skeletons

### 3.1 `neosr/utils/factory.py`

```python
import importlib, inspect
from collections.abc import Mapping
from typing import Any
from neosr.config import ConfigError

Table = Mapping[str, tuple[str, str | None]]   # name -> (module under package, scale kwarg | None)

def resolve(table: Table, package: str, section: str, name: Any) -> Any:
    if name not in table:
        raise ConfigError(f"[{section}] unknown type {name!r}", key=str(name), known=table)
    return getattr(importlib.import_module(f"{package}.{table[name][0]}"), name)  # ImportError propagates

def inject_scale(table: Table, section: str, name: str, kwargs: dict, scale: int | None) -> None:
    kw = table[name][1]
    if kw is None:
        return
    if scale is None:
        raise ConfigError(f"[{section}] {name} needs the run scale")
    if kwargs.setdefault(kw, scale) != scale:
        raise ConfigError(f"[{section}] {kw}={kwargs[kw]} contradicts scale={scale}")

def construct(obj: Any, section: str, name: str, kwargs: dict, **extra: Any) -> Any:
    try:
        return obj(**kwargs, **extra)
    except TypeError as err:
        try:
            inspect.signature(obj).bind(**kwargs, **extra)
        except TypeError as bad:                      # the kwargs themselves are wrong -> config problem
            raise ConfigError(f"[{section}] {name}: {bad}") from err
        raise                                         # ctor-body bug: keep it a TypeError with traceback
```

```python
# neosr/data/prefetch_dataloader.py
class CUDAPrefetcher:
    def __init__(self, loader: DataLoader, device: torch.device) -> None:
        self.loader, self.device = loader, device
        self.stream = torch.cuda.Stream(device); self._it = None; self.batch = None
    def reset(self) -> None:
        self._it = iter(self.loader); self._preload()
    def _preload(self) -> None:
        try:
            batch = next(self._it)
        except StopIteration:
            self.batch = None; return
        with torch.cuda.stream(self.stream):
            self.batch = {k: v.to(self.device, non_blocking=True) if torch.is_tensor(v) else v for k, v in batch.items()}
    def next(self) -> dict | None:
        cur = torch.cuda.current_stream(self.device); cur.wait_stream(self.stream)
        batch = self.batch
        if batch is not None:
            for v in batch.values():
                if torch.is_tensor(v):
                    v.record_stream(cur)
        self._preload()
        return batch
```

## 6. Risks

- **RNG streams change by design.** Loss curves for the same seed will differ from before the migration. The gates are equivalence at fixed weights, plus "runs, saves, resumes, converts".
- **Switching the loader defaults** (D21) raises host RAM use: persistent workers stay alive, and pinned buffers are held. This is an owner question.
- **The single-GPU gloo smoke test covers control flow only.** NCCL, multi-node and `find_unused_parameters` remain untested on real hardware.
- **Lanes interlock.** L-A cannot merge without I-1. L-C depends on T4 lane A. L-D and L-E depend on the T1 and T2 schedules. I-1 is the single integration point.
- **Coverage gaps in the arch matrix:** tiling and deploy paths (`plainusr_arch.py:73` must take device and dtype from its weights) and archs limited to scale 2. These are listed explicitly as xfail with a reason, never skipped silently.

## 7. Rejected ideas (one-line reasons)

From the draft:
- **Hard error for unknown keys:** breaks private configs that work today; replaced by a warning plus a clean-repo test (D6).
- **The `rng()` shim during migration:** one name cannot be both a function and a `Generator`; replaced by an atomic switch (D17).
- **Deleting `train_dctlsa.toml:88`:** still invalid TOML and drops FDL; replaced by restoring the missing header (D29).
- **One `obj(**kwargs)` builder for all five packages:** the call shapes differ (D3).
- **`output.new_zeros(())` as the loss accumulator:** accumulates in bf16/fp16 under autocast (D20).
- **DySample `arange` in `x.dtype`:** changes bf16 rounding (D20).
- **krgn "build the eye on `x.device`":** there is no `x` in the ctor (D20).
- **Blanket `TypeError -> ConfigError`:** hides ctor bugs behind exit 2 without a traceback (D4).
- **S1 lanes as independent:** they share import contracts; replaced by a merge gate and I-1.
- **Device edits to `msswd_loss.py:14` and `topiq.py:180`:** already device-correct (`msswd_loss.py:42,148`, `topiq.py:277`).
- **Unconditional save on `KeyboardInterrupt`:** not a resumable boundary (D24).

From the critiques:
- **Fable A9, "`validate_train` requires all OTF degradation keys":** T2's `Degrader` already validates them at construction; a second validator would drift.
- **Codex P1-3, "`self.param_key` is never initialized":** false, `base.py:399` sets it. The underlying raw-dict problem is real and handled by T2 D9.
- **Codex P2-12, "warn now, strict later":** no planned flip, because the warning plus the clean-repo test already achieve the goal.
- **Codex P2-13, "fix the JPEG order bug in T3":** already in T2 step 1b's acceptance (both orders honour `jpeg_compress`).
- **A `train.total_iter` alias (T1 §2.7):** 0 configs use it.

Carried over from earlier rounds:
- Typed config structs (msgspec or pydantic); a `Config` singleton or contextvar; a cached `net_opt`.
- Signature introspection for the scale; renaming ported scale parameters.
- Per-dataset `RandomStreams` and `rng=` plumbing (revisit if one process ever hosts two stochastic datasets).
- A scoped default device; adding `device=` to factory calls that already work.
- try/except auto-discovery or silent import fallbacks.
- An explicit `deterministic` key, a strictness switch or CLI overrides (D30).
- Exact mid-epoch resume and `sampler.set_epoch(start_index)`; the limitation is documented in D18.
