## 0. Summary

1. **Three trainer files.** `base.py` holds generic plumbing, `image.py` is the SR trainer, and `otf.py` is `image` plus one `feed_data` override. `model_type` stays `image`/`otf`, resolved through T3's explicit `MODELS` table. The four legacy trainers and `image.py.helaman` are deleted.
2. **OTF synthesis lives in data code.** It moves to `neosr/data/otf_degradation.py` (`Degrader`, `PairPool`) and is built only when training.
3. **One canonical eager module per net** (`self.net_g`, `self.net_d`) handles load, save, EMA, validation and test. A separate execution wrapper (`self.net_*_fwd` = `compile(DDP(net))`, or less) is used only for the training forward.
4. **Construction order:** build → pretrained → [T5 QAT slot] → (inference returns here) → D → EMA → phases → resume → wrap. Resume loads into the bare modules before DDP's broadcast and before compile.
5. **Two artifacts.**
   - `models/net_{g,d}_<u>.pth` = `{"params": sd}`. G is the EMA if enabled, otherwise the schedule-free `x` weights or the plain live weights. D is the live D.
   - `training_states/<u>.state` (format 2) is self-contained: live nets, EMA, per-phase optimizer/scaler/schedulers, counters, RNG, best metrics, and a small `run` compatibility record.
6. **One persisted counter**, `update` (completed optimizer windows), owned by the model. Losses receive `it = update + 1`. Saves happen only at update boundaries.
7. **Graceful stop.** DataLoader workers are spawned with SIGINT ignored, so a terminal Ctrl-C reaches only the main process (probe). The first Ctrl-C finishes the current update, saves, and exits 0 without validating. A second Ctrl-C raises `KeyboardInterrupt` (exit 130), and the last committed checkpoint stands. Under DDP the flag is all-reduced.
8. **`eval_weights()`** serves validation and export.
   - With EMA, it uses the EMA module.
   - Otherwise it uses the live module. When the optimizer is really schedule-free (decided from the optimizer, not a `hasattr` check), it swaps to `x` and restores exactly afterwards, including the per-module train flags and the optimizer's `train_mode`.
9. **Tiled inference** uses fixed tiles snapped inside the image, with a context halo (`val.tile_overlap`, default 16) and a core crop, stitched into a CPU buffer.
   - It is exact for translation-equivariant archs whose receptive field is at most the halo and whose stride/window lattice is respected.
   - Otherwise it is approximate, and still better than today's overlap-free tiles.
10. **Atomic writes:** serialize once to a temp file → fsync → `os.replace`, retried only on `PermissionError` (Windows locks) → directory fsync. The `.state` is written before the exports. `keep_states = 3`. A failed or incompatible resume raises (`ConfigError` when the config changed). Legacy v1 states are refused with a pointer to `pretrain_network_*`.
11. **One weight reader**, `read_weights()`, for train/test/convert. An explicit `param_key` wins or errors. Otherwise the precedence is `params_ema` > `params-ema` > `params` > a bare dict. The prefixes `module.` and `_orig_mod.` are stripped and `n_averaged` is dropped.
12. **Losses carry no run-random state.** FDL draws its projections from a fixed-seed generator, so a resumed run computes the same objective.

## 3. Construction order (`image.__init__(opt, runtime)`)

```
0. defaults: self.net_d = self.ema = None; self.phases = {}; self.update = self.epoch = self.micro = 0;
             self.best_metric_results = {}; self._evaluating = False; self._pending_rng = None;
             self.data_generator = None
1. self.net_g = build_network(opt["network_g"], scale=s, section="network_g").to(device, memory_format=mf)
2. if pretrain_network_g and not resuming: load_weights(net_g, read_weights(path, param_key_g), strict_load_g)
3. [T5 QAT slot: prepare (and load a QAT-kind pretrain) — topology final after this line]
   self.nets = {"net_g": self.net_g}
   if not is_train: return                                     # test.py: eager, no wrap, no optimizer/loss/D/EMA
4. net_d: same as 1-2 (if network_d); self.nets["net_d"] = self.net_d
5. self.ema = Ema(self.net_g, ema) if ema > 0 else None        # deep copy; initialised at the first update
6. losses (T1 build_losses); self.phases = {name: Phase(...) for name in self.nets}   # optimizer from trainable(net)
7. if resuming: self.resume(Path(opt["path"]["resume_state"]))  # into the bare modules and phases
8. self.net_g_fwd = self.wrap(self.net_g); self.net_d_fwd = self.wrap(self.net_d)    # DDP, then compile; last
```

Invariant: everything that captures parameter identity or buffer shape is created after the last structural change (step 3) and before wrapping. That covers EMA lists, `Phase.params`, optimizer param lists and the names. Resume copies into those same tensors, and DDP and compiled graphs see the copies [F-probe]. Under DDP every rank loads the state, because optimizer state is not broadcast, and the DDP constructor broadcast then starts from identical weights.

`trainable(net) -> (names, params)` = `[(n, p) for n, p in net.named_parameters() if p.requires_grad]`. It is the only source of both the optimizer's param list and the names stored in the state.

## 5. Training loop, stop, DDP

### 5.1 Loop contract (`train.py` belongs to T3; this is the T2 interface)

```python
def train(cfg, rt):
    p = cfg["path"]
    explicit = p.get("resume_state")
    resume = Path(explicit) if explicit else (latest_state(Path(p["training_states"])) if cfg["auto_resume"] else None)
    if explicit and not resume.is_file():
        raise FileNotFoundError(f"resume_state {resume} does not exist")
    p["resume_state"] = resume
    if resume is None:
        make_exp_dirs(cfg)                                    # fresh run; never on resume
    model = build_model(cfg, rt)                              # resume happened inside (§3 step 7)
    loader, sampler, val_loaders = build_loaders(cfg, rt)     # T3; ConfigError on 0 train batches / empty val (D27)
    model.data_generator = loader.generator                   # part of the RNG state (T3 D18)
    log_macs(model)                                           # D28: bare nets, eval, no_grad
    total = cfg["logger"]["total_iter"]
    if model.update >= total:
        logger.info("nothing to do: update %d >= total_iter %d", model.update, total); return
    stop = StopFlag(); stop.install()
    prefetcher = CUDAPrefetcher(loader, rt.device)            # T3: ctor only stores
    model.restore_rng()
    epoch = model.epoch
    while True:
        model.epoch = epoch
        sampler.set_epoch(epoch)
        prefetcher.reset()                                    # iter(loader) under sigint_ignored() (D19)
        while (batch := prefetcher.next()) is not None:
            model.feed_data(batch)
            if not model.optimize_parameters():               # inside a window
                continue
            u = model.update
            stopping = stop.requested(rt.device)              # all_reduce(MAX) under DDP, local bool otherwise
            done = stopping or u >= total
            if u % print_freq == 0 or done:
                msg_logger({"epoch": epoch, "iter": u, "lrs": model.current_lr(), **model.get_current_log()})
            if done:
                model.check_finite()                          # T1: raises before NaN reaches disk
                model.save(final=True)                        # state first, then exports + *_latest
                if not stopping:
                    for vl in val_loaders: model.validation(vl, u, tb_logger, save_img)
                return
            val_due, save_due = bool(val_loaders) and u % val_freq == 0, u % save_freq == 0
            if val_due or save_due:
                model.check_finite()
            if val_due:
                for vl in val_loaders: model.validation(vl, u, tb_logger, save_img)
            if save_due:
                model.save()
        epoch += 1
```

```python
class StopFlag:
    """1st SIGINT: request a stop at the next update boundary. 2nd: KeyboardInterrupt (exit 130)."""
    def __init__(self) -> None:
        self._set = False
    def install(self) -> None:
        signal.signal(signal.SIGINT, self._on_sigint)
    def _on_sigint(self, *_):                    # no logging/IO in the handler
        self._set = True
        signal.signal(signal.SIGINT, signal.default_int_handler)
    def requested(self, device: torch.device) -> bool:
        if not torch.distributed.is_initialized():
            return self._set
        t = torch.tensor(float(self._set), device=device)
        torch.distributed.all_reduce(t, op=torch.distributed.ReduceOp.MAX)   # all ranks leave together
        return bool(t.item())

@contextmanager
def sigint_ignored():
    """Processes spawned inside inherit SIG_IGN across exec, so a terminal Ctrl-C reaches only the trainer."""
    prev = signal.signal(signal.SIGINT, signal.SIG_IGN)
    try:
        yield
    finally:
        signal.signal(signal.SIGINT, prev)
```

The loop logs "stop requested: saving update u" once it sees the flag. A Ctrl-C that arrives during the few milliseconds of `iter(loader)` is ignored, which is an accepted window. With `accumulate = k`, a stop can consume up to k−1 more micro-batches. This is safe because workers no longer die.

### 5.3 Evidence for D19

`t2final/sigint_inherit.py` runs a spawn DataLoader with 3 workers, both persistent and per-epoch, in its own process group, and sends `killpg(SIGINT)` right after `iter()` (bootstrap) and mid-epoch. Result: every worker reports `SIG_IGN` at `worker_init_fn`, 40/40 batches arrive, the flag is set, and the run prints OK. The control (`sigint_control.py`, no bracket) fails with `RuntimeError DataLoader worker (pid …) is killed by signal: Interrupt.` These are the same failures Fable recorded (`worker.py:369`, `signal_handling.py:73`).

### 5.4 DDP rules (thin seam)

- Only rank 0 writes files, validates and restores RNG. Validation sits between two `barrier()` calls.
- G pass: T1 calls the **bare** `self.net_d` (no reducer) with `backward(inputs=G params)`. D pass: `self.net_d_fwd`.
- With `accumulate > 1`, non-boundary micro-batches run **forward and backward** inside `net_fwd.no_sync()` (`distributed.py:1454` docstring). `OptimizedModule` forwards `.no_sync` [Fable-verified]. This is a T1 seam: the context must open before `net_g_fwd(g_in)`.
- Under DDP, export with SF and no EMA temporarily changes rank-0 parameters only between update boundaries, and restores them exactly before rank 0's next forward. The other ranks' next all-reduce waits for it.

### 6.1 `eval_weights()` (image.py)

```python
@contextmanager
def eval_weights(self):
    """Generator to evaluate, in eval mode. Restores what it changed: SF params, optimizer train_mode
    flags, per-module training flags. Arch-internal eval caches (SPAN eval_conv) are recomputed by the
    arch on every eval forward and are not restored. Never entered inside inference_mode; never saves."""
    if self.ema is not None:
        yield self.ema.module                                    # permanently eval, requires_grad False
        return
    net, phase = self.net_g, self.phases.get("net_g")          # phases == {} on the inference path
    was, modes = net.training, [(m, m.training) for m in net.modules()]
    snap = flags = None
    try:
        if phase is not None and phase.sf:
            flags = [g["train_mode"] for g in phase.opt.param_groups]
            snap = [p.detach().clone() for p in net.parameters()]
            phase.opt.eval()                                     # p <- x
        net.eval()
        self._evaluating = True
        yield net
    finally:
        self._evaluating = False
        net.train(was)                                           # runs arch train() overrides
        for m, t in modes:
            m.training = t                                       # then the exact per-module flags
        if snap is not None:                                     # never opt.train(): a second lerp is not a bit-inverse
            with torch.no_grad():
                torch._foreach_copy_(list(net.parameters()), snap)
            for g, f in zip(phase.opt.param_groups, flags):
                g["train_mode"] = f
```

The snapshot restore matters under DDP. Only rank 0 validates, and a lossy round trip would leave its weights different from the other ranks' with nothing to re-sync them. T5 adds `disable_observer` for QAT modules inside this context (T5 D11).

### 6.4 `neosr/models/tiling.py`

```python
def _starts(n: int, tile: int, halo: int) -> list[int]:
    return [0] if n <= tile else [*range(0, n - tile, tile - 2 * halo), n - tile]

def _core(s: int, n: int, tile: int, halo: int) -> tuple[int, int]:     # LR span this tile writes
    return (s + halo if s > 0 else 0), (s + tile - halo if s + tile < n else n)

def infer_tiled(net, lq, scale: int, tile: int, halo: int, out_device="cpu"):
    """Fixed tile x tile windows snapped inside the image (smaller only when the image is). Each writes its
    core, so context never leaves the image. Exact iff RF <= halo and the arch is translation-equivariant on
    the tile lattice (tile, tile-2*halo and the image size multiples of its stride/window). Output stitched on
    out_device (CPU: tiling exists for memory; 8K x4 fp32 is 5.9 GiB)."""
    _, _, h, w = lq.shape
    out = None
    for y in _starts(h, tile, halo):
        y0, y1 = _core(y, h, tile, halo)
        for x in _starts(w, tile, halo):
            x0, x1 = _core(x, w, tile, halo)
            o = net(lq[..., y:y + tile, x:x + tile])
            if out is None:
                out = torch.empty(o.shape[0], o.shape[1], h * scale, w * scale, dtype=o.dtype, device=out_device)
            out[..., y0 * scale:y1 * scale, x0 * scale:x1 * scale] = \
                o[..., (y0 - y) * scale:(y1 - y) * scale, (x0 - x) * scale:(x1 - x) * scale]
    return out
```

- `val.tile = -1` (the default) keeps meaning full-image inference.
- `val.tile_overlap` is a new optional key.
- T4's blended `infer()` (`T4_draft.md` ~l.227) is superseded.
- Coverage was checked by Fable over n ∈ [1, 600) × 6 (tile, halo) pairs: no gaps and no duplicate last start.

### 7.3 Resume tolerance

| Changed in TOML | Behaviour |
|---|---|
| lr, loss weights, frequencies, `total_iter`, datasets, `accumulate`, batch size | Allowed. Optimizer `param_groups` (lr) come from the state, as today (documented). |
| `network_d` added or removed | `ConfigError`: the net/phase key sets differ; use `pretrain_network_*`. |
| network options that change names or shapes | `ConfigError` wrapping torch's strict-load message. |
| network options that keep the shapes (e.g. `img_range`) | Warning naming the changed keys (from the `run` record). |
| optimizer type, schedule-free mode, the trainable parameter list | `ConfigError` naming the first differing parameter. |
| scheduler type list | `ConfigError` (0 configs use schedulers). |
| `use_amp`/`bfloat16` | Warning. An fp16 scaler with an empty saved state starts fresh; a saved scaler state is ignored when fp16 is off. |
| `ema` 0 → >0 | Info: the first update copies live G. |
| `ema` >0 → 0 | Warning: the saved EMA is ignored. |
| world size | Warning: ranks ≠ 0 reseed, as at startup. |

Every raise happens inside `__init__` and aborts the run, so partially loaded in-memory state never matters.

### 7.4 Pretrained reading

`read_weights` accepts `{"params_ema"|"params-ema"|"params": sd}` or a bare tensor dict, with any number of leading `module.`/`_orig_mod.` prefixes and with or without `n_averaged`. It does not use `mmap`, because legacy non-zip files reject it.

`strict_load_* = true` (the default) means exact names and shapes. With `false`, shape mismatches are dropped with a warning, missing and unexpected keys are listed, and zero matches raise.

```python
def strip_prefixes(sd):
    out = OrderedDict()
    for k, v in sd.items():
        while k.startswith(_PREFIXES):
            k = k.split(".", 1)[1]
        if k == "n_averaged":
            continue
        if k in out:
            raise KeyError(f"prefix stripping collides on {k!r}")
        out[k] = v
    return out

def cpu_copy(sd):
    return OrderedDict((k, v.detach().to("cpu", memory_format=torch.contiguous_format, copy=True)) for k, v in sd.items())

def read_weights(path, param_key=None):
    obj = torch.load(path, map_location="cpu", weights_only=True)
    if "format" in obj and "nets" in obj:
        raise ConfigError(f"{path} is a training state; pretrain from models/net_*_<update>.pth or resume it")
    if param_key is not None:
        if param_key not in obj:
            raise ConfigError(f"{path}: param_key {param_key!r} not found; keys: {list(obj)[:10]}")
        return strip_prefixes(obj[param_key])
    for key in ("params_ema", "params-ema", "params"):
        if key in obj:
            return strip_prefixes(obj[key])
    if obj and all(isinstance(v, torch.Tensor) for v in obj.values()):
        return strip_prefixes(obj)
    raise ConfigError(f"{path}: no parameter mapping; keys: {list(obj)[:10]}")

def load_weights(net, sd, strict, log):
    if not strict:
        own = net.state_dict()
        for k in [k for k in sd if k in own and own[k].shape != sd[k].shape]:
            log.warning(f"shape mismatch, skipped {k}: {tuple(sd[k].shape)} -> {tuple(own[k].shape)}")
            del sd[k]

            raise ConfigError("pretrained file matches no tensor of the network")

    for k in res.missing_keys: log.warning(f"missing: {k}")
    for k in res.unexpected_keys: log.warning(f"unexpected: {k}")

def atomic_save(obj, path: Path, attempts: int = 3) -> None:
    fd, tmp = tempfile.mkstemp(dir=path.parent, prefix=f".{path.name}.", suffix=".tmp")
    try:
        with os.fdopen(fd, "wb") as f:
            torch.save(obj, f)
            f.flush()
            os.fsync(f.fileno())
        for attempt in range(attempts):              # Windows: a viewer holding the target
            try:
                os.replace(tmp, path)
                break
            except PermissionError:
                if attempt == attempts - 1:
                    raise
                time.sleep(1)
    except BaseException:
        with contextlib.suppress(OSError):
            os.unlink(tmp)
        raise
    if os.name == "posix":
        dfd = os.open(path.parent, os.O_RDONLY)
        try:
            os.fsync(dfd)
        finally:
            os.close(dfd)

def rng_state(device: torch.device | None = None, loader_gen: torch.Generator | None = None) -> dict:
    _, key, pos, has_gauss, gauss = np.random.get_state()
    cuda = device is not None and device.type == "cuda"
    return {"python": random.getstate(),
            "numpy": {"key": torch.from_numpy(key.astype(np.int64)), "pos": int(pos),
                      "has_gauss": int(has_gauss), "gauss": float(gauss)},
            "neosr": neosr_rng.get_state(), "torch": torch.get_rng_state(),
            "cuda": torch.cuda.get_rng_state(device) if cuda else None,
            "loader": loader_gen.get_state() if loader_gen is not None else None}

def set_rng_state(s, device=None, loader_gen=None) -> None:
    random.setstate(s["python"])
    n = s["numpy"]
    np.random.set_state(("MT19937", n["key"].numpy().astype(np.uint32), n["pos"], n["has_gauss"], n["gauss"]))
    neosr_rng.set_state(s["neosr"]); torch.set_rng_state(s["torch"])
    if s["cuda"] is not None and device is not None and device.type == "cuda":
        torch.cuda.set_rng_state(s["cuda"], device)
    if s["loader"] is not None and loader_gen is not None:
        loader_gen.set_state(s["loader"])

@contextmanager
def preserved_rng(device=None):
    s = rng_state(device)
    try:
        yield
    finally:
        set_rng_state(s, device)
```

### 8.3 `base.py`: save, resume, RNG

```python
def save(self, *, final: bool = False) -> None:
    if self._evaluating or self.micro % self.accumulate:
        raise RuntimeError("save() only at an update boundary, outside eval_weights()")
    if self.rt.rank != 0:
        return
    u, p = self.update, self.opt["path"]
    states, models = Path(p["training_states"]), Path(p["models"])
    atomic_save(self.training_state(), states / f"{u}.state")             # authoritative first
    for name, sd in self.export_state_dicts().items():
        payload = {"params": sd}
        atomic_save(payload, models / f"{name}_{u}.pth")
        if final:
            atomic_save(payload, models / f"{name}_latest.pth")
    prune_states(states, self.keep_states)

def training_state(self) -> dict:
    return {"format": STATE_FORMAT, "update": self.update, "epoch": self.epoch,
            "nets": {n: m.state_dict() for n, m in self.nets.items()},
            "ema": self.ema.state_dict() if self.ema is not None else None,
            "phases": {n: ph.state_dict() for n, ph in self.phases.items()},
            "rng": rng_state(self.device, self.data_generator),
            "best": self.best_metric_results, "run": self.run_record()}

def resume(self, path: Path) -> None:
    log = get_root_logger()
    state = torch.load(path, map_location="cpu", weights_only=True)
    if "format" not in state:
        raise ConfigError(f"{path}: legacy training state cannot be resumed; start a new run with "
                          f"pretrain_network_g = models/net_g_{state.get('iter')}.pth (and _d)")
    if state["format"] != STATE_FORMAT:
        raise ConfigError(f"{path}: unsupported state format {state['format']}")
    for kind in ("nets", "phases"):
        saved, now = sorted(state[kind]), sorted(getattr(self, kind))
        if saved != now:
            raise ConfigError(f"{path}: {kind} {saved} saved, {now} configured; use pretrain_network_* for a new run")
    for n, net in self.nets.items():
        try:
            net.load_state_dict(state["nets"][n])                          # strict
        except RuntimeError as e:
            raise ConfigError(f"{path}: {n} does not match the configured network:\n{e}") from e
    for n, ph in self.phases.items():
        ph.load_state_dict(state["phases"][n], log)
    if self.ema is not None and state["ema"] is not None:
        self.ema.load_state_dict(state["ema"])
    elif state["ema"] is not None:
        log.warning("saved EMA ignored: ema is disabled")
    for key, (old, new) in dict_diff(state["run"], self.run_record()).items():
        log.warning(f"changed since {path.name}: {key}: {old!r} -> {new!r}")
    self.update, self.epoch = state["update"], state["epoch"]
    self.best_metric_results = state["best"]
    self._pending_rng = state["rng"]
    log.info(f"resumed {path.name}: update {self.update}, epoch {self.epoch}. Exact: weights, EMA, optimizers, "
             "schedulers, scalers, counters, model-side RNG (rank 0). Restarted: data order, augmentation, OTF pool.")

def restore_rng(self) -> None:                # train.py: the last call before the loop
    if self._pending_rng is not None and self.rt.rank == 0:
        set_rng_state(self._pending_rng, self.device, self.data_generator)
    self._pending_rng = None

def wrap(self, net):
    if net is None:
        return None
    if self.rt.distributed:
        net = DistributedDataParallel(net, device_ids=[self.device.index],
                                      find_unused_parameters=self.opt.get("find_unused_parameters", False))
    if self.opt.get("compile"):
        net = torch.compile(net, mode=self.opt.get("compile_mode", "default"), dynamic=False)   # T4 P7
```

## 11. Risks

- **Continuation scope.** Exact: weights, EMA, optimizers, schedulers, scalers, counters, and rank-0 model-side RNG (E1 to E3 prove this). Not exact: data order inside the resumed epoch, worker augmentation streams, the OTF pool, and other ranks' RNG. The resume log says so.
- **State size.** Each state grows by about 160 MB (esrgan); `keep_states = 3` bounds the total.
- **Tiling.** Exactness holds only under the D13 conditions. Global or channel attention and windowed archs keep faint seams, reduced by the halo.
- **DDP.** Logic is tested with gloo; NCCL and throughput are not tested here. A rank-0 validation exception leaves the other ranks at the barrier until the NCCL timeout, but the last checkpoint stands.
- **Behaviour changes, intended and documented.**
  - The SF export without EMA is `x` (today `y`).
  - `net_d_*.pth` holds live D (today EMA D).
  - A final `.state` is written.
  - The read precedence is unified.
  - Older `.state` files are pruned after the third.
  - FDL projections become identical across runs.
- **Same-shape network option changes on resume** produce only a warning (the `run` record). The owner may want them fatal (§13).
- **`optimizer.load_state_dict` restores lr** over TOML lr changes (status quo; documented).

## 12. Rejected ideas (one-line reasons)

- **R1. Codex: `ImageTrainer` + preparation protocol + factory + 8 files.** The same two batch paths, with more types (D1).
- **R2. Codex: cut DDP entirely.** The seam is 6 lines and logic-tested on this machine; T3 keeps the launcher contract.
- **R3. Fable: reset `SIGCHLD` to `SIG_DFL` and discard the partial window on stop.** `SIG_IGN` inheritance (probe) removes the cause: workers never see Ctrl-C, so neither workaround is needed.
- **R4. Fable: treat a loader `RuntimeError` after the stop flag as end of data.** It would mask real worker crashes.
- **R5. Codex: persist loss `state_dict`s.** It would persist frozen backbones; a fixed-seed FDL draw removes the only run-random loss state.
- **R6. Codex: make same-shape network option changes fatal.** The owner may change such options deliberately; a named warning is enough (open question 3).
- **R7. Codex: GPU stitching by default plus an option key.** 0 configs tile, tiling exists for memory, and a new key buys nothing.
- **R8. Codex: claim tiling exactness per verified arch (SwinIR/HAT/RCAN tests).** Those archs are approximate by construction; the condition is documented and tested on a synthetic strided net.
- **R9. Codex: "fix derived caches in owning archs" as part of T2.** SPAN's `eval_conv` is recomputed on every eval forward, so it is harmless. Marking it non-trainable is optional arch hygiene (archs lane).
- **R10. Codex: require an explicit fresh-run action when `auto_resume` finds no state.** Archiving is a non-destructive rename (status quo), and the hazardous case (failed requested resume) now raises.
- **R11. Codex: keep micro-batch units for `wavelet_init`/ECO thresholds.** `accumulate` is unset in every config, so no shipped run shifts; one unit is simpler.
- **R12. Codex: explicit per-net G/D checkpoint code instead of dict loops.** The two comprehensions over `self.nets`/`self.phases` add no abstraction and no type dispatch.
- **R13. Codex: 7-field progress, per-optimizer update counters, `latest.json`, a provenance block, per-rank gathered RNG, a persisted OTF pool, DataParallel, partial-continuation `ignore_resume_networks`.** Each was rejected in the draft for size or zero users.
- **R14. Fable: drop the world-size warning.** It costs one field in the `run` record that is stored anyway.
- **R15. Fable: accept a `.state` as a `pretrain_network_*` source.** There is no request for it; it now raises with a hint (open question 4).
- **R16. Fable: `AveragedModel`.** It costs a host sync per update and needs `n_averaged`; first-update semantics come from T1's `Ema`.
- **R17. Fable: ragged tiles and a CPU-stitch option.** Fixed tiles keep window archs and cudnn autotune stable; CPU stitching is simply the behaviour.
- **R18. Fable: a separate `build` block, persisting `micro`.**
- **R19. Opus draft: v1 adapter, `keep_states = 0`, `hasattr` SF gate, stitching on GPU, D15 "QAT out of the trainer", `fork_rng` for validation.** Each was superseded above.
- **R20. All: mid-window saves, partial-gradient persistence, async saving, safetensors by default, a generic N-network abstraction, keeping `default.py` "for reference".**
