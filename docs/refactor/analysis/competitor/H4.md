## Do not port

- **RCAN `res_scale` "fix"**: in the target the scale multiply is commented out (`rcan_arch.py:107-108`), so `res_scale=scale` is dead. At most, delete the unused argument when touching the file.
- **DySample `pin_memory` "crash fix"**: no crash on torch 2.9.1 (probe). Optional cleanup when touching the file: `x.new_tensor([W, H])`, build `coords` on `x.device`. The competitor's own `C/archs/arch_util.py:384` still has it, and `:339` rejects valid `in_channels == groups`.
- **Competitor Adan-SF as a "corrected" optimizer** (`adanschedulefree_optim.py:150-199`): same warmup bug. Take only the closure and restart ideas (#8).
- **Competitor `MetaUpsample` uint8 buffer, the `mosrv2.load_state_dict` hack and `LDA_AQU`** (`arch_util.py:302-316,428-572,718-732`): overflow, caller-dict mutation, `xavier_uniform(m)` on a module, `meshgrid` without `indexing`, divide-by-zero for 1-pixel outputs.
- **Per-image metric factories and the competitor's RGB metric contract** (`metrics/dists.py`, `topiq.py`, `lpips.py`, `metric_util.py:45`): no caching, and RGB→Y would corrupt the target's BGR luminance metrics. Do not use the tensor-PSNR 80 dB cap.
- **FlexNet SDPA removal**: it loses the fast path. Fix SDPA instead (#1).
- **FlexNet `self.conv5x5_reparam.weight = nn.Parameter(...)`** (`C/archs/flexnet_arch.py:142`): replaces the parameter, which breaks optimizer ownership and compile.
- **Optimizer registry with eager module scan + `pytorch_optimizer` imports** (`C/optimizers/__init__.py`): the target already has one dispatch. SOAP/ADOPT/StableAdamW would be a separate feature decision.
- **Spandrel/timm/transformers dependency surface** (`C/pyproject.toml`): the wrapped archs carry their own problems. `rrdbnet_arch.py:21` derives unshuffle from the channel ratio and drops `out_nc`, and `realcugan_arch.py:34` drops channel counts for ×2. Keep the target's local 10–20-line helpers.
- **Behaviour-changing defaults presented as fixes**:
  - RealPLKSR `layer_norm=True` (`realplksr_arch.py:143`) breaks official weights.
  - LMLT hard-coded `window_size=8` (`lmlt_arch.py:376`).
  - Sebica loses `mini`/SECA and the output clamp.
  - EIMN loses the `norm` kwarg.
  - `rgb_mean=0.4488…` is a policy choice.
  - MAN mean shift and MetaGAN2/3 are arch variants needing experiments.
- **Multiscale PatchGAN scalar output** (`patchgan_arch.py:39`): averages away the per-patch map that the target's GAN losses need.
- **Competitor checkpoint and meshgrid regressions**: `dat_arch.py:844` and `hit_srf_arch.py:643` drop `use_reentrant=False`, and `hat_arch.py:1038-1073` and `hit_srf_arch.py:301` call `meshgrid` without `indexing`. The target is already better here.
- **`topiq_arch.py:11-35` custom downloader with `print`**: use `torch.hub.load_state_dict_from_url`.

## Summary

1. Fix first: FlexNet SDPA (#1), the SF save ordering (#2), window padding (#3), SSIM→∞ (#4), the VGG local-load crash (#5). All are small and have clear tests.
2. Neither repo has metric-network caching, a correct Adan-SF warmup, or safe reparam invalidation. Write these ourselves; the competitor supplies only the direction.
3. Two Fable claims were disproved by the code (RCAN `res_scale` is dead; DySample `pin_memory` does not crash on torch 2.9.1), and parts of Fable #4 and #5 were wrong. Codex's "optimizer factory" is redundant in the target.
